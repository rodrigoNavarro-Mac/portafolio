# Rodrigo Navarro · Portfolio

Recruiter-first portfolio built with Next.js, TypeScript, Tailwind CSS, and `next-intl`.

The site presents four engineering case studies through architecture diagrams:

- Agente Capital
- Chatwoot Capital Plus
- Punto Tierra
- Carmen Cárdena Boutique

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Spanish is the default locale and English is available at `/en`.

## Checks

```bash
npm run lint
npm run build
```

The contact form requires `EMAIL_USER` and `EMAIL_PASS` environment variables.
